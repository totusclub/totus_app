# Ringback Tone

Place `ringback.mp3` in this directory.

## How to add ringback.mp3:

1. Get a ringback tone audio file (MP3 format)
2. Name it `ringback.mp3`
3. Place it in this directory: `android/app/src/main/res/raw/ringback.mp3`

The ringback tone will play when making outgoing calls and stop when the call is answered.

## Recommended specifications:
- Format: MP3
- Duration: 3-5 seconds (will loop automatically)
- Sample rate: 44100 Hz
- Bitrate: 128 kbps
- Channels: Mono or Stereo
